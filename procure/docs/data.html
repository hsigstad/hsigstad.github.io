BEC state procurement — consolidated (Licitações do Estado de SP)

Source

  • provider: BEC/SP (Bolsa Eletrônica de Compras) — São Paulo state's electronic procurement platform
  • access: data/Licitações do Estado de SP/
  • documentation:

Files

  • BEC_consolidated.csv — ~4M rows, 83 columns (semicolon-delimited)
    • one row per item per purchase order (OC)
    • columns include: purchase order details, item descriptions, buyer unit, supplier info, bid counts by phase, prices, firm characteristics (CNPJ, CNAE, size, location, distance to buyer)
  • BEC_bid_to_bid.csv — ~2.3M rows, 52 columns
    • one row per bid per item per auction
    • columns include: auction dates, item details, unit price proposed, negotiated price, reference price, winner flag, item quantities

Coverage

  • time period: (sample — full universe for recent period forthcoming)
  • geographic scope: São Paulo state (state-level purchases, not municipal)
  • population: state procurement via BEC electronic platform

Unit of observation

  • consolidated: item × purchase order (OC)
  • bid_to_bid: bid × item × auction

Key variables

  • numerodaoc — purchase order number
  • proc_compra — procurement procedure type
  • preco_final — final price
  • numbids_ph1–ph7 — number of bids by auction phase
  • firm_cnpj — supplier CNPJ
  • cnae_fiscal / cnae_descr — supplier industry classification
  • porte_empresa — firm size
  • dist / dist1 / dist2 / dist3 — distance measures (buyer–supplier)
  • same_municip — buyer and supplier in same municipality
  • Flag Vencedor (bid_to_bid) — winner indicator
  • Valor Unitário Proposta / Valor Unitario Negociado (bid_to_bid) — bid and negotiated prices

Sample restrictions

  • state-level purchases only (not municipal)

Data quality

Public notices — editais

Source

  • provider: scraped from BEC/SP by Darcio Genicolo-Martins
  • access: data/edital/
  • documentation:

Files

  • 8 sample .txt files (full set forthcoming)
  • filenames encode procedure IDs, e.g. 080102000012011OC00097_edital.txt
  • content: HTML-sourced text from BEC/SP system ("Sistema BEC/SP")

Coverage

  • time period: (sample — full set forthcoming)
  • geographic scope: São Paulo state
  • population: state public bids

Unit of observation

  • one file per public notice (edital)

Key variables

  • procedure ID (ordem de compra) — encoded in filename
  • procedimento licitatório number — contained in text
  • links court case references to procurement procedure IDs

Sample restrictions

  • state-level bids only (not municipal)
  • 8 files in current sample

Data quality

Judicial case files (example_procurement_cases.csv)

Source

  • provider: TJSP (Tribunal de Justiça do Estado de São Paulo)
  • access: data/example_procurement_cases.csv
  • documentation:

Files

  • example_procurement_cases.csv — ~3,700 rows, ~130 MB

Coverage

  • time period: various (cases with decisions from ~2013 onwards in sample)
  • geographic scope: São Paulo state
  • population: procurement-related judicial cases (improbidade administrativa, ação civil pública, etc.)

Unit of observation

  • one row per case

Key variables

  • num_npu — CNJ unified case number
  • classe — case type (e.g., Ação Civil Pública)
  • assunto — subject (e.g., Improbidade Administrativa)
  • magistrado — judge name
  • comarca / foro / vara — court jurisdiction
  • data — decision date
  • text — full decision text (sentença)

Sample restrictions

  • sample of ~3,700 cases (full universe forthcoming)

Data quality

  • full text available for LLM-based scheme classification

CGU sorteio audit reports

Source

  • provider: CGU (Controladoria-Geral da União) — Programa de Fiscalização por Sorteios Públicos / FEF
  • access: ../../data/CGU/
  • documentation: each cycle randomly selects ~60 municipalities nationwide for federal-transfer audits

Files

  • Ciclo 02/ through Ciclo 40/ — individual PDF audit reports per municipality (37 cycles, ~2,100 reports total, 4.8 GB)
    • filename format: {id}_{cycle}-{UF}-{Municipality}.pdf
    • 178 reports for SP municipalities across all cycles
  • Ciclo20_40.xlsx — structured finding-level data for cycles 20–40 plus V-series
    • 84,706 rows, 23 columns
    • 5,280 findings for SP across 131 SP municipalities
  • Relatórios Auditorias/ — (empty)

Coverage

  • time period: cycles 02–40 (~2003–2015) plus V-series (verification cycles)
  • geographic scope: nationally sampled municipalities; 131 unique SP municipalities in xlsx
  • population: federal transfers to municipalities (health, education, social assistance, infrastructure)

Unit of observation

  • PDFs: one report per municipality per cycle
  • xlsx: one row per audit finding (constatação) per program per municipality

Key variables (xlsx)

  • Etapa_Sorteio_ou_Ciclo_FEF — cycle number
  • Municipio / Cod_Mun_IBGE / UF — municipality identifiers
  • Montante_fiscalizado — audited amount in R$
  • Funcao / Subfuncao / Programa / Acao — functional classification
  • Tipo_constatacao — severity: Falha Grave (13,281), Falha Média (65,298), Falha Formal (860), Informação (3,225)
  • descricao_sumaria_constatacao — free-text description of the irregularity found

SP findings by function (top 5)

  • Saúde: 1,694 | Assistência Social: 1,189 | Educação: 1,234 | Comércio e Serviços: 192 | Urbanismo: 214

Sample restrictions

  • only municipalities selected by random lottery (not census)
  • SP coverage: 131 of 645 municipalities (~20%)

Data quality

  • function/subfunction labels have inconsistent casing across cycles (e.g., "SAUDE" vs "Saúde")
  • xlsx covers cycles 20–40 only; cycles 02–19 available as PDFs only

Municipal procurement (TCE-SP — Licitações Municípios Estado de SP)

Source

  • provider: TCE-SP (Tribunal de Contas do Estado de São Paulo) — Portal da Transparência Municipal
  • URL: https://transparencia.tce.sp.gov.br/conjunto-de-dados
  • access: data/Licitações Municípios Estado de SP/
  • documentation: Audesp system; see also saude project docs/data.md for detailed TCE-SP documentation

Files

  • licitacao-2024-11_0.zip — 47 MB (November 2024)
  • licitacao-2024-12_0.zip — 49 MB (December 2024)
  • despesas-2012.zip — 976 MB (municipal expenditures 2012)

Coverage

  • time period: sample months (full series 2018+ forthcoming for licitações; 2008–2024 for despesas)
  • geographic scope: 644 municipalities in São Paulo state (capital excluded — falls under TCM-SP)
  • population: municipal procurement and expenditures

Unit of observation

  • licitações: procurement event level
  • despesas: line-item expenditure (empenho / liquidação / pagamento)

Key variables (despesas)

  • ds_municipio / codigo_municipio_ibge — municipality
  • tp_despesa — type: Empenhado / Liquidado / Pago
  • vl_despesa — value in R$
  • ds_modalidade_lic — procurement modality (PREGÃO, DISPENSA, etc.)
  • historico_despesa — free-text description (can contain judicial markers)
  • ds_funcao_governo / ds_subfuncao_governo — functional classification

Sample restrictions

  • sample months only (full universe forthcoming)

Data quality

  • encoding: ISO-8859-1 (not UTF-8)

TRF4 court cases (appeals)

  • access: data/lavajato/trf4/
  • 5000553-66.2017.4.04.7000/ — Ação Penal: corruption + money laundering (Mariano Marcondes Ferraz), 13ª VF Curitiba; 144 PDFs (422 MB)
  • 5001580-21.2016.4.04.7000/ — Ação Penal: financial crimes + money laundering, Curitiba; 67 docs (136 MB)
  • 0050095-58.2019.4.04.7000/ — reference case (minimal, 1 HTML file)
  • user has full TRF4 Lava Jato archive available for additional cases

Coverage

  • time period: 2004–2019 (peak 2014–2018)
  • geographic scope: national (Curitiba, Rio, São Paulo, Brasília/STF)
  • SP-relevant: Metrô Lines 2/5/6, Rodoanel Sul/Norte, DERSA, Sis. Viário Metropolitano
  • population: Petrobras procurement cartel, state infrastructure corruption, political bribery

Key content for this project

  • Plea agreement testimony — detailed operational descriptions of how procurement cartels worked: bid rotation, bribery mechanics, payment channels, intermediary roles
  • SP denúncias — formal charges documenting specific procurement fraud schemes in São Paulo state infrastructure (Metrô, Rodoanel, DERSA), with amounts, participants, and scheme mechanics
  • Curitiba denúncias — Petrobras procurement cartel: how construction companies divided contracts, fixed bids, paid bribes through intermediaries (doleiros), and maintained the cartel over a decade
  • Sentenças — court findings establishing facts about how corruption was organized

Data quality

  • STF delações: 65 of ~117 collaborators have unsealed documents; many remain under seal
  • denúncias are prosecution charges (allegations, not proven facts); sentenças are court findings
  • some PDF filenames have duplicate extensions (.pdf.pdf)
