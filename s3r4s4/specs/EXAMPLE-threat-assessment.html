    This file is an illustrative example, not a live spec. It shows the idiom we want for real specs: concrete file/line references, explicit variable names, and a populated Results and feedback section that closes the loop. Do not run this.

    Status: example Priority: — Requested by: — For: paper §4.3 (threat assessment), Table 4

    What to change

    Our identification assumes vara leniency affects downstream outcomes only through the plaintiff-win decision. To support this, produce a single table that regresses each of the following non-merits case attributes on the leave-one-out vara leniency bias_vara, conditional on foro × filing-year fixed effects:

    Outcome Variable Definition
    Settlement settled sentenca == "ACORDO"
    Time to decision days_to_sentence data_sentenca - data_distribuicao
    Preliminary injunction granted tutela_granted 1 if mov table contains "concedo a tutela" or "defiro a liminar" before sentence date
    Log damages award log_damages log(1 + valor_danos_morais); valor_danos_morais parsed from sentence text via the existing regex in do_regression_by_cnpj.do line ~240
    Defendant appeared defendant_appeared 1 if mov contains "contestação" within 30 days of citation

    In Stata, add a block after the first-stage section of do_regression_by_cnpj.do (around line 480, just before the main IV call):

    foreach y in settled days_to_sentence tutela_granted log_damages defendant_appeared {
    reghdfe `y' bias_vara, absorb(comarca_id#year_processo) vce(cluster vara)
    estimates store thr_`y'
}
esttab thr_* using "Tables/threat_assessment.tex", replace ///
    b(3) se(3) star(* 0.1 ** 0.05 *** 0.01) booktabs

    Keep the foro × filing-year FE identical to the main IV spec — do not add vara FE (that would absorb the instrument).

    Rationale

    A referee will immediately ask whether lenient varas also settle faster, grant more injunctions, or award larger damages — any of which would violate exclusion. A zero (or small, signed-in-a-specific-way) coefficient on each row rules out the corresponding alternative channel. This is the standard diagnostic in the judge-leniency literature (Bhuller et al. 2020 Table 4; Dobbie et al. 2018 Table 3).
